# TPStreams Integration Skill

Expert guide and index for integrating TPStreams video infrastructure, including Mobile SDKs (Flutter, Android, iOS, React Native), DRM Service (Widevine, FairPlay, CBCS), Server APIs, Live Streaming, Direct Video Upload, Subtitles, and Webhooks.

---

## Core Domain Concepts

- **Asset**: The fundamental resource in TPStreams. An Asset can represent a **video**, a **folder** (hierarchical organizational container), or a **live stream**.
- **Playback Authentication and Access Tokens**: Video playback is secured through short-lived, signed `access_token` strings generated by your backend server. Client players require both the `asset_id` and `access_token` to authorize playback.
- **DRM (Digital Rights Management)**: Premium anti-piracy protection. TPStreams supports Google Widevine (Android, Windows, Linux, modern browsers) and Apple FairPlay (iOS, macOS Safari). It uses **CBCS (Common Encryption)** so a single encrypted asset set serves both DRM providers.
- **Webhooks**: Asynchronous HTTP callbacks delivering real-time status updates to your backend for background events, including video transcoding job progress/completion and live stream lifecycle changes (started, active, stopped).
- **Subtitles and Captions**: Caption tracks in WebVTT format. TPStreams supports custom `.vtt` uploads as well as **automated AI-generated subtitles** derived directly from the audio track.
- **Direct Video Upload (Upload Session)**: A direct-to-storage upload mechanism. Your backend creates an upload session, enabling client or server uploaders to stream video bytes directly into TPStreams storage without routing heavy video files through your web server.
- **Live Streaming**: Real-time video broadcasting supporting instant provisioning, scheduled events, status webhooks, and embedded real-time chat via Chat SDK.
- **Transcoding**: Automated cloud video processing that converts uploaded master files into adaptive bitrate multi-resolution streams (HLS/DASH).
- **TPStorage**: S3-compatible cloud object storage for managing files and media assets using standard S3 client libraries with Access Key and Secret Key authentication.
